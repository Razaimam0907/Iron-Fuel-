# IRONFUEL - Gym Supplements Store

Everything is in this ONE folder (no sub-folders): HTML, CSS, JavaScript and all images.
Open `index.html` in a browser, or use VS Code "Live Server".

## Files
- `index.html`  - page shell (indented, one element per line)
- `style.css`   - all styles (one declaration per line, grouped by section)
- `data.js`     - products, FOOD DATABASE, product-page content
- `app.js`      - router, cart, checkout, one-time gift, scroll animations
- `product.js`  - product detail page
- `nav.js`      - search bar (live suggestions, typo tolerance, results page) and hamburger menu
- `diet.js`     - calorie calculator, BMI, diet plan with live food search, PDF export
- `chat.js`     - chatbot
- `*.jpg`       - product images (whey.jpg, oats.jpg, pb.jpg ...)

## Product order (shop grid)
Premium Whey, Isolate, Mass Gainer, Creatine Monohydrate, Creatine Micronized, Pre-Workout,
BCAA Power, Multivitamin, Omega-3 Fish Oil, High Protein Oats, High Protein Peanut Butter.
Change the order or add products in the `P` array in `data.js`.

Libraries (Lenis smooth scroll, jsPDF) load from a CDN, so you need internet.
